# 解决前端项目启动问题

## 问题分析
根据错误信息 `'vite' 不是内部或外部命令，也不是可运行的程序或批处理文件`，以及对项目结构的检查，发现前端项目缺少 `node_modules` 目录，这意味着项目依赖项尚未安装。

## 解决方案
1. **安装项目依赖**：在前端项目目录 `IGS-front1.1.8` 中运行 `npm install` 命令，安装所有必要的依赖项，包括 `vite`。

2. **启动开发服务器**：依赖安装完成后，再次运行 `npm run dev` 命令启动开发服务器。

## 执行步骤
1. 打开命令行终端
2. 导航到 `c:\Users\吴紫丹\Desktop\IGS\IGS-front1.1.8` 目录
3. 运行 `npm install` 命令
4. 等待依赖安装完成
5. 运行 `npm run dev` 命令启动项目

这样应该能够成功启动前端开发服务器，解决当前的启动问题。
