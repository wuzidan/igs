### 修复历史记录API返回空数据问题

**问题分析**：
API返回空数据的原因是代码使用了错误的模型关系。具体来说：
1. 代码中使用 `request.user.practice_records.all()` 获取练习记录，这对应 `PracticeRecord` 模型
2. 但数据库中实际数据存储在 `historyrecord_historyrecord` 表中，对应 `HistoryRecord` 模型
3. 代码已正确获取 `history_records_model`，但统计逻辑和历史记录构建仍使用 `practice_records`

**修改方案**：
1. **修改统计数据计算**：将基于 `practice_records` 的统计改为使用 `history_records_model`
2. **修复历史记录构建**：从 `history_records_model` 中构建历史记录列表，而不是 `practice_records`
3. **调整字段映射**：确保使用正确的字段名称（例如 `duration` 字段，而非 `duration_minutes`）
4. **修复题型和难度统计**：确保从正确的关联关系中获取题目数据

**代码修改**：
```python
# 修改前（第31-109行）
# 1. 计算基本统计数据
total_attempts = practice_records.count()
# 平均分计算
avg_score = practice_records.aggregate(avg=Avg('score'))['avg'] or 0
avg_score = round(avg_score)
# 总时长计算（直接使用practice_records中的duration_minutes字段）
total_minutes = sum(record.duration_minutes for record in practice_records)

# 修改后
# 1. 计算基本统计数据
total_attempts = history_records_model.count()
# 平均分计算
avg_score = history_records_model.aggregate(avg=Avg('score'))['avg'] or 0
avg_score = round(avg_score)
# 总时长计算（使用history_records_model中的duration字段）
total_minutes = 0
for record in history_records_model:
    # 解析duration字段，例如"11分钟" → 11
    try:
        total_minutes += int(record.duration.split('分钟')[0])
    except (ValueError, IndexError):
        continue
```

**完整修改内容**：
1. **统计数据计算**：使用 `history_records_model` 替代 `practice_records`
2. **总时长计算**：解析 `duration` 字符串，提取分钟数
3. **最高分计算**：从 `history_records_model` 中获取最高分记录
4. **历史记录构建**：从 `history_records_model` 中构建历史记录列表
5. **题型和难度统计**：确保从正确的关联关系中获取题目数据
