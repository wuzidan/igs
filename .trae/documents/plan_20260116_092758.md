### 修改知识结构可视化API实现课程-章节-知识点关联展示

**问题分析**：
当前知识结构可视化页面显示为空，原因是API只返回了默认课程和章节，没有从数据库中获取真实的课程-章节-知识点关联数据。系统已存在完整的实体和关系模型，但API未正确利用这些关系。

**修改方案**：

1. **获取真实课程列表**：从Course模型获取所有课程
2. **构建课程-章节关联**：通过CourseChapter关系表获取每个课程的章节列表
3. **构建章节-知识点关联**：

   * 利用现有的关系链：Chapter → (缺失chapter\_exercise) → Exercise → exercise\_challenge → Challenge → challenge\_topic → Topic

   * 由于缺少chapter\_exercise关系，暂时通过课程关联的练习题来间接获取知识点
4. **计算统计数据**：为每个课程和章节计算平均掌握程度
5. **返回完整数据结构**：确保前端能正确展示课程、章节和知识点的层级关系

**代码修改**：

```python
# 修改KnowledgeStructureView的get方法

# 1. 获取所有课程
courses = Course.objects.all()
course_list = []

for course in courses:
    # 2. 获取课程关联的章节
    chapters = Chapter.objects.filter(
        chapter_courses__course=course
    ).order_by('chapter_courses__position')
    
    chapter_list_for_course = []
    for chapter in chapters:
        # 3. 获取章节关联的知识点（通过课程-练习题-挑战题-知识点的关系链）
        # 获取课程关联的练习题
        exercises = Exercise.objects.filter(
            exercise_courses__course=course
        )
        
        # 获取练习题关联的挑战题
        challenges = Challenge.objects.filter(
            exercise_challenges__exercise__in=exercises
        )
        
        # 获取挑战题关联的知识点
        topics = KnowledgeTopics.objects.filter(
            challenge_relations__challenge__in=challenges
        ).distinct()
        
        # 构建章节数据
        chapter_data = {
            "id": chapter.id,
            "courseId": course.id,
            "name": chapter.name,
            "avgMastery": 0,  # 后续计算
            # 章节关联的知识点ID列表
            "topicIds": [topic.topic_id for topic in topics]
        }
        chapter_list_for_course.append(chapter_data)
    
    # 构建课程数据
    course_data = {
        "id": course.id,
        "name": course.name,
        "avgMastery": 0,  # 后续计算
        "chapters": chapter_list_for_course
    }
    course_list.append(course_data)
```

* 支持课程和章节的筛选功能

* 正确计算并显示知识点掌握程度

**技术要点**：

1. **多级关系查询**：处理复杂的多对多关系链
2. **数据结构设计**：确保返回的数据结构符合前端需求
3. **性能优化**：使用distinct()和适当的查询优化避免重复数据
4. **灵活性处理**：当缺少直接关系时，通过间接关系链实现需求
5. **统计计算**：为每个层级计算相应的统计数据

这个修改方案能够利用现有的数据库关系，实现课程-章节-知识点的完整关联展示，满足用户的需求。
