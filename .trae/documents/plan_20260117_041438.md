### 修改predict\_question\_accuracy函数调用真正的AAKT模型

**问题分析**：
当前的`predict_question_accuracy`函数只是基于历史正确率进行简单预测，没有真正调用训练好的AAKT模型。需要修改该函数，正确使用QUESTION_MAP将数据库中的question_id映射到模型内部索引，然后调用模型进行预测。

**修改方案**：

1. **正确使用QUESTION_MAP**：
   - 使用QUESTION_MAP将数据库中的question_id映射到模型内部索引
   - 如果映射不存在，使用默认值或基础预测结果

2. **准备模型输入**：
   - 将用户历史交互转换为模型需要的input_ids序列
   - 准备对应的input_times序列（暂时使用默认值）
   - 构建合适的标签序列

3. **调用AAKT模型**：
   - 使用加载好的全局模型MODEL
   - 构建模型输入张量
   - 调用模型的forward方法
   - 获取模型预测结果

4. **处理模型输出**：
   - 从模型输出中提取预测概率
   - 将模型输出转换为0-1之间的正确率
   - 确保输出格式符合函数要求

**代码修改**：

```python
def predict_question_accuracy(user_id, question_id, interactions):
    # 基础预测逻辑：基于用户历史正确率
    if interactions:
        correct_count = sum(1 for inter in interactions if inter.get('correct', False))
        base_accuracy = correct_count / len(interactions)
    else:
        base_accuracy = 0.5  # 默认中等水平
    
    # 如果模型可用，尝试使用模型进行更精确的预测
    if MODEL_AVAILABLE and MODEL is not None and TORCH_AVAILABLE:
        print(f"Using model to predict accuracy for question {question_id}")
        
        try:
            # 1. 使用QUESTION_MAP将数据库question_id映射到模型内部索引
            model_question_id = QUESTION_MAP.get(str(question_id), None)
            if model_question_id is None:
                print(f"Question {question_id} not found in QUESTION_MAP, using base prediction")
                return base_accuracy
            
            # 2. 准备输入数据
            # 构建输入序列：历史交互 + 要预测的题目
            input_sequence = []
            for inter in interactions:
                # 将历史交互转换为模型输入格式
                # 首先获取模型内部索引
                hist_model_qid = QUESTION_MAP.get(str(inter['question_id']), None)
                if hist_model_qid is None:
                    continue  # 跳过映射不存在的题目
                
                # 正确答案：correct_token_id = NUM_QUESTIONS
                # 错误答案：incorrect_token_id = NUM_QUESTIONS + 1
                if inter.get('correct', False):
                    input_sequence.append(hist_model_qid)
                    input_sequence.append(MODEL.correct_token_id)
                else:
                    input_sequence.append(hist_model_qid)
                    input_sequence.append(MODEL.incorrect_token_id)
            
            # 添加要预测的题目
            input_sequence.append(model_question_id)
            
            # 如果输入序列为空，返回基础预测
            if not input_sequence:
                return base_accuracy
            
            # 3. 转换为张量
            input_ids = torch.tensor([input_sequence], dtype=torch.long, device=DEVICE)
            input_times = torch.zeros_like(input_ids, dtype=torch.float, device=DEVICE)
            labels_kts = torch.full_like(input_ids, -100, device=DEVICE)
            labels_tags = torch.full((input_ids.shape[0], input_ids.shape[1], NUM_TAGS), -100, dtype=torch.float, device=DEVICE)
            
            # 4. 调用模型
            with torch.no_grad():
                _, _, _, preds_kts = MODEL(input_ids, input_times, labels_kts, labels_tags)
            
            # 5. 处理模型输出
            # preds_kts形状：[bs, seq_len, 2]，表示每个位置的正确/错误概率
            # 获取最后一个位置的预测结果（要预测的题目）
            last_pred = preds_kts[0, -1]  # 取第一个batch的最后一个位置
            # 使用softmax获取概率
            prob = torch.softmax(last_pred, dim=0)
            model_accuracy = prob[1].item()  # 正确概率
            
            print(f"Model predicted accuracy for question {question_id}: {model_accuracy}")
            return model_accuracy
        except Exception as e:
            print(f"Error calling model: {str(e)}")
            # 如果模型调用失败，返回基础预测结果
            return base_accuracy
    else:
        print(f"Using base prediction for question {question_id}")
        return base_accuracy
```
